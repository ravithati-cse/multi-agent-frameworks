# Menu & Substitution Policy

If an item is out of stock (stockout), the Inventory agent flags a shortage. The Kitchen
and Support agents then choose one of: (a) substitute a comparable item of equal or lower
price with the customer's consent, (b) delay the order with a clear updated ETA, or
(c) cancel-with-refund following the Refund Policy. Silence is never acceptable.

Promotions apply only at order intake and never change refund-approval thresholds.
Loyalty tier affects promotions and priority ordering only — it does NOT grant any agent
additional tool scopes and does NOT auto-approve refunds.
