# Menu Substitution Policy

## When Substitution Is Allowed
- A substitution may be offered when an ordered item is out of stock mid-prep.
- The Kitchen agent must check with the Inventory agent before proposing a substitution.
- Substitutions must be from the same category (e.g., burger → chicken sandwich, not burger → salad).

## Customer Consent
- For orders placed via the Support agent on behalf of a customer, the Support agent must notify
  the customer of the substitution and wait for confirmation before proceeding.
- If the customer declines, the order must be cancelled with a full refund.

## Automatic Substitutions (no consent required)
- Side items (fries, drinks) may be substituted with equivalent items without customer consent.
- Substituted items must be the same or lower price. If lower price, the difference is refunded automatically.

## Allergen Rules
- The Kitchen agent must never substitute an item if the replacement contains an allergen
  noted in the customer's profile.
- If no safe substitution exists, the order must be partially fulfilled or cancelled.

## Documentation
- All substitutions must be logged as a ticket (category=inquiry) so the Support agent can
  follow up with the customer after delivery.
